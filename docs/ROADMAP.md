# FinSearch Roadmap

This document holds longer-term capabilities that are not committed to a current
implementation PR. See [Architecture](ARCHITECTURE.md) for the implemented system and
[Implementation Plan](IMPLEMENTATION_PLAN.md) for ordered, accepted work.

## Candidate capabilities

- Quarterly structured facts
- Multi-period structured calculations
- Structured multi-company comparison
- Broader metric registry
- Native hybrid claim typing
- Parallel KB and structured execution
- Durable event-driven filing monitoring
- Watchlist and portfolio workflows
- Cache and rate-limit optimization
- Production observability dashboards

Prioritization requires a separate implementation plan with acceptance criteria.
